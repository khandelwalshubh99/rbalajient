## Build order
```
node build/build.js                                            # industries + map
cd repo && python3 build-catalogue-pages.py                    # products + sitemap
python3 build-index.py "Balaji Enterprises.dc.html" index.html # home
```
`build.js` writes the map that `build-catalogue-pages.py` reads, so run it first.
